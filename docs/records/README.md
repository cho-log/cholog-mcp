# 기록

이 프로젝트가 여기까지 온 과정이다. 무엇을 왜 그렇게 정했는지 궁금할 때 읽는다.

## 읽기 전에

- **기록은 갱신하지 않는다.** 작성한 날의 판단과 숫자 그대로다. 지금의 기준은 [도구 명세](../tool-spec.md)이고, 둘이 다르면 명세가 맞다.
- **실제 사람은 가렸다.** 스터디원과 리뷰어의 GitHub ID, 이름은 적지 않고 PR 번호만 남긴다. 새 기록을 쓸 때도 같다.
- 본문에 나오는 `[0]`, `[1]`, `[5]` 같은 번호는 당시 작업 단계의 이름이다. 아래 표의 "단계"와 같다.
